## 1. 背景与目标

在 H5 孩子端**档案选择页底部**（用户标注的红框区域）新增「游戏乐园」入口，提供纯前端益智小游戏，作为知识闯关之外的思维训练补充。小游戏与闯关体系（科目、积分、每日限额）**完全独立**。

> v3.0 更新：游戏乐园入口已整合至儿童成长乐园主导航页（`Home.vue` 三大功能模块卡片之一），详见 `02-儿童成长乐园.md`。

## 2. 已确认决策

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 登录要求 | **免登录随便玩**：无需选档案/PIN，打开即玩 |

- 游戏页面复用现有深色主题变量与触屏交互习惯（大按钮、防误触）

## 4. 功能需求 — v2.1 基础游戏

### 4.1 F-GAME-02 华容道经典闯关

**模式 A：传统华容道**（4 列 × 5 行棋盘）
- 棋子：曹操 2×2、竖将 1×2×4、横将 2×1、兵 1×1；滑动移动，一步一格/多格
- 胜利：曹操移出底部出口
- 关卡：内置经典布局 ≥10 关（横刀立马、指挥若定、兵分三路、近在咫尺等），按最少步数难度排序，逐关解锁
- 辅助：步数统计、撤销、重排；"提示"用内置 BFS 求解器给出下一步最佳走法（每关限 3 次）

**模式 B：路径规划**（Rush Hour 式）
- 6×6 棋盘，横/竖滑块（长 2~3），红色目标车移到右侧出口
- 关卡：内置 ≥12 关，三档难度各 4 关，逐关解锁
- 辅助：步数统计、撤销、BFS 提示

**思维训练标注**：每关开始前显示 1 秒即逝的标注卡，如「思维重点：空间想象 · 步骤预判」，关卡列表页每关也带标签

### 4.2 F-GAME-03 数独王者

- **三档难度**：四宫格（2×2）、六宫格（2×3）、九宫格（3×3）；四/六宫为题库内置（各 ≥30 题随机抽），九宫格为**生成器实时生成**（回溯生成终盘→对称挖洞→求解器验证唯一解）
- 交互：点格→弹数字键盘；冲突数字高亮标红；同行/列/宫自动淡显相同数字
- **智能提示系统**：①"检查"按钮标出当前所有错误 ②"提示"按钮自动填一格正确答案（每题限 3 次）
- 辅助：计时器、完成庆祝动画；四宫格适合入门、六宫格为四年级建议起点（界面标注推荐）

### 4.3 F-GAME-04 成语接龙

- 内置小学常用成语库 **≥200 条**（含拼音、释义），其中 ≥60 条含**出处/典故**（如"负荆请罪——《史记·廉颇蔺相如列传》…"）
- **四种题型**（每关混合出现）：
  1. **接龙**：给出成语，从 4 个选项中选下一个以尾字开头的成语（选项来自成语库首字索引）
  2. **填空**：成语缺 1~2 字，从候选字中补全
  3. **看图猜词**：emoji 组合猜成语（手写映射 ≥40 条，如 🐎🀄→马到成功 用更贴切组合），4 选 1
  4. **补全释义**：给释义选对应成语
- **关卡制**：6 关 × 每关 5 题，难度递进（常用→进阶）；答错即时显示正确答案与释义
- **通关典故展示**：每关通关页随机展示本关 1~2 个成语的出处典故卡片
- 辅助：错题即时讲解、关卡通关星级（按正确率）

### 4.4 ~~F-GAME-05 顽皮小鳄鱼爱洗澡~~（v2.2 已替换为拼图游戏）

> **v2.2 变更**：小鳄鱼爱洗澡（网格水流模拟）操作门槛偏高，已替换为更适合小学生、平板与电脑通用的**拼图游戏**。原 `/games/water` 路由移除，文件 `waterLevels.ts`、`WaterGame.vue` 已删除。

## 5. 功能需求 — v2.2 拼图游戏（F-PUZZLE，替换小鳄鱼）

> 版本：v2.2 · 阶段 10
> 日期：2026-09-25
> 变更：删除"小鳄鱼爱洗澡"，替换为"拼图游戏"；游戏乐园其余部分（华容道/数独/成语接龙）不变

### 5.1 已确认决策

| # | 决策 | 结论 |
|---|------|------|
| 1 | 内置素材来源 | 代码绘制主题插画（不用课本扫描图，规避版权）；同时支持上传本地照片 |
| 2 | 集成方式 | 集成进游戏乐园（Vue 组件替换小鳄鱼），非独立三文件 |
| 3 | 科目范围 | 语文 + 数学（与现有科目体系一致，不含英语） |

### 5.2 F-PUZZLE-01 入口与替换
- 游戏乐园大厅：🐊 小鳄鱼卡片替换为 🧩 拼图卡片
- 档案页入口副标题同步更新为"华容道 · 拼图 · 数独 · 成语接龙"
- 路由 `/games/water` 移除，新增 `/games/puzzle`
- 删除文件：`waterLevels.ts`、`WaterGame.vue`；games store 中 `water` 进度键替换为 `puzzle`（旧水进度自然废弃，不迁移）

### 5.3 F-PUZZLE-02 素材
- **内置插画 6 张**（Canvas 代码绘制，卡通风格，标注课本来源）：
  - 语文（人教版四上）：《观潮》钱塘江大潮 / 《爬山虎的脚》攀墙 / 《蟋蟀的住宅》草丛洞府
  - 数学（北师大版四上）：《大数的认识》算盘 / 《线的认识》与角 / 《买文具》生活场景
- **上传图片**：`<input type="file" accept="image/*">`，FileReader 读取，居中裁剪为正方形后切块
- 图片选择页：横滑/网格缩略图，选中的图 + 难度 → 开始

### 5.4 F-PUZZLE-03 难度
- 简单 3×3 / 普通 4×4 / 困难 5×5 / 挑战 6×6（全部开放，不设关卡锁）

### 5.5 F-PUZZLE-04 玩法（交换式拼图）
- 拼图块网格铺满棋盘，随机打乱（保证初始不是完成态）
- **拖拽**：按住一块拖到另一块上松手 → 两块交换；支持鼠标与触屏（touch 事件，兼容 iPad/iOS 11）
- **点选交换**：轻点两块也可交换（同一交互双通道）
- 拖拽中拼图块放大 + 阴影反馈；放到目标位置有轻微吸附动画
- 可选开关：显示拼图块编号（默认关）

### 5.6 F-PUZZLE-05 校验与完成
- 每块放对位置时淡入绿色边框提示（不锁定，仍可移动）
- 全部归位 → 弹窗"恭喜完成！"，显示用时、步数、星级，撒花动画

### 5.7 F-PUZZLE-06 计时与步数
- 开始拼图自动计时，顶部实时显示；完成显示最终用时
- 每次交换计 1 步，顶部实时显示；完成显示总步数

### 5.8 F-PUZZLE-07 操作
- 「重新开始」：同图同难度重新打乱，计时步数清零
- 「查看原图」：按住查看（按钮按下显示原图浮层，松开隐藏）；也可随时点缩略图参考
- 「换一张/换难度」：返回素材选择页

### 5.9 F-PUZZLE-08 星级（进度入档）
- 星级按**步数效率**评定：设 N×N 块，基准步数 = 打乱时错位块数
  - 3 星：步数 ≤ 错位数 × 1.3
  - 2 星：步数 ≤ 错位数 × 1.8
  - 1 星：完成即得
- 进度 key：`puzzle-3` / `puzzle-4` / `puzzle-5` / `puzzle-6`，存入 games store（星级只升不降），大厅显示拼图总星数与完成难度数

### 5.10 拼图界面与技术方案
- 风格与游戏乐园一致（圆角卡片、大按钮、适合触屏）
- 布局：顶部（计时/步数/编号开关）→ 中间拼图棋盘（居中，宽度自适应）→ 底部（查看原图/重新开始/换一张）
- iOS 11 兼容：touch 事件（非 PointerEvent）、无 replaceAll、静态 import
- `views/games/Puzzle.vue` + `games/puzzleArt.ts`（Canvas 绘制内置插画）
- 切块：每块 `background-position` 偏移显示原图对应区域（DOM + CSS 方案，无需 canvas 切图）
- 打乱：Fisher-Yates，保证与原位不同块 ≥ 80%

## 6. 功能需求 — v2.3 贪吃蛇（F-SNAKE，新增第五款游戏）

> 版本：v2.3 · 阶段 11
> 日期：2026-09-25
> 状态：已定稿，待用户批准
> 前置：阶段 10（拼图大师）已上线

### 6.1 已确认决策

| 决策项 | 结论 |
|---|---|
| 集成方式 | **集成进游戏乐园**：游戏核心逻辑用 ES5 + Canvas 原生实现（IIFE 封装），包在 Vue SFC 组件中挂在 `/games/snake` 路由；其余四个游戏保持不变 |
| 最高分存储 | 接入现有设备级进度 `localStorage['xxs_games_progress_v1']`，新增 `snake: { best: number }`（不产生积分、不关联孩子档案，与乐园其它游戏一致） |
| 大厅入口 | GameHub 新增 🐍 贪吃蛇卡片（显示最高分）；ProfileSelect 副标题追加「贪吃蛇」 |

### 6.2 F-SNAKE-01 画布与界面
- Canvas 绘制主画布，背景 #333333；网格线 #666666、透明度 0.3、间隔 10px（隐约可见）
- 画布自适应 iOS 11 平板屏幕，游戏区保持 16:9 比例，页面居中，无滚动条
- 画布上方固定信息栏：「当前得分: X」「最高分: Y」
- 按钮统一样式：背景 #444444、白字、8px 圆角、:active 变深反馈

### 6.3 F-SNAKE-02 元素样式
- 蛇头 #00FF00、蛇身 #00DD00，圆角矩形（圆角半径 10%）
- 食物 #FF0000 圆形，半径 = 格子 40%；生成位置避开蛇身

### 6.4 F-SNAKE-03 初始状态
- 蛇长 3 节，位于画布中心偏左，向右移动，速度 1 格/秒
- 开始前画布显示「点击开始」提示，等待用户操作

### 6.5 F-SNAKE-04 得分与成长
- 每吃 1 个食物 +10 分，蛇身 +1 节
- 每累计 5 个食物速度提升 20%（interval 缩短），提升时画布短暂闪烁反馈

### 6.6 F-SNAKE-05 碰撞检测
- 撞边界、撞自身 → 游戏结束；吃到食物 → 得分 + 增长
- 游戏结束：半透明黑色遮罩（70%），居中显示「游戏结束」、最终得分、「重新开始」按钮

### 6.7 F-SNAKE-06 方向控制
- 防反向：正在向右时按左无效，以此类推
- 方向输入在下一次移动时生效，避免瞬间转向自撞

### 6.8 F-SNAKE-07 控制方式
- 键盘：方向键 + WASD，带防抖（同一 tick 内重复输入去重）
- 触摸：画布下方十字方向键区，4 个按钮各 ≥60×60px、间距 ≥10px，绝对定位布局，touchstart 响应（消除 300ms 延迟）
- 功能按钮：「开始游戏」（未开始/结束时显示）、「暂停/继续」（进行中显示，文字随状态切换）

### 6.9 F-SNAKE-08 iOS 11 兼容
- 组件内布局禁用 Flex/Grid，用绝对定位/float
- viewport meta 已有（index.html 全局），游戏容器加 `touch-action: none`
- 触摸事件阻止默认行为，防滚动缩放；游戏核心代码 ES5（var/function/IIFE，无箭头函数/class/Promise/解构）
- Canvas 用 2D API 基础能力（无 roundRect 等新 API，圆角用 arcTo 手绘）

### 6.10 贪吃蛇技术方案
- 新建 `src/views/games/Snake.vue`：游戏核心（状态机 waiting/running/paused/over、tick 循环、碰撞、绘制）以 ES5 IIFE 实现，组件负责生命周期挂载/卸载与 UI 状态绑定
- 修改 `stores/games.ts`：GameKey 增加 `'snake'`，进度结构 `snake: { best: number }`，新增 `recordSnakeBest(score)`（只增不减）
- 修改 `GameHub.vue`：新增 🐍 卡片（显示「最高分 N」）；`ProfileSelect.vue` 副标题更新
- 路由：`/games/snake`（免登录，静态 import，同现有四游戏）

## 7. 非功能需求

1. 全部游戏可离线运行（资源打包进构建产物，无新增网络请求）
2. 触屏友好：滑块拖动带跟手效果，棋子最小可点区域 ≥ 40px
3. 兼容 iOS 11 WebView（ES2017 语法边界，静态 import）
4. 每个游戏首屏 < 1s（大厅→游戏切换无长加载）
5. 进度存储失败（隐私模式）时静默降级为内存态，不影响游玩
