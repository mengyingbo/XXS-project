## 1. 背景与目标

孩子学完每课后，需要练习「看拼音写词语」。在语文每课最后新增一个**词语关卡**：
题目只出拼音，孩子在**田字格手写区域**逐字手写作答；写完后点「对照答案」查看正确词语，
自评「写对了 / 写错了」计入判分（方案 A，无自动识别）。

## 4. 功能需求

### F-WORD-01 题型定义（HAND）
- 新题型 `HAND`：stem = 词语拼音（带声调、按字空格分隔，如 `qí guān`、`nuǎn huo`）；
  answer = 可接受答案数组 `["奇观"]`（复用 BLANK 的答案格式，通常 1 项）；options 为 NULL。
- 题目其余字段与现有一致（analysis 写词义/提示，knowledge_point='词语表'）。

### F-WORD-02 手写作答组件（HandwriteInput.vue）
- 题干下方显示拼音（大号、按字分组对齐）。
- 拼音下方一排**田字格**（每字一格，Canvas 绘制田字格虚线），孩子逐格手写。
- 笔迹：黑色圆头线条，Canvas 2D；touchstart/touchmove/touchend + mousedown 双通道，`touch-action: none` 防滚动。
- 每格支持**撤销上一笔**和**清空本格**；「对照答案」按钮在全部格子写过后可用。
- 点「对照答案」→ 显示正确词语（大号）+ 两个自评按钮「✓ 写对了」「✗ 写错了」：
  - 写对了 → 以目标词语作为 userAnswer 提交（后端判对）；
  - 写错了 → 以必定不匹配的哨兵文本提交（后端判错，反馈区显示正确答案）。
- 不做自动识别、无键盘兜底（避免抄写作弊，纯练手写）。

### F-WORD-03 判分与计分
- 后端 `HAND` 判分逻辑与 BLANK 相同（normalize 后比对）；userAnswer 由自评结果生成（见 F-WORD-02）。
- 计分沿用现有规则：答对 +10、3 连对 +5、首通关 +20、首次三星 +30；答错不扣分、进错题本。
- 词语关卡计入每日答题配额（chinese 科目）。
- 后端 session start 继续对 HAND 题下发 answer 字段（供「对照答案」展示）。

### F-WORD-04 错题本与结算
- 答错的词语进错题本；错题本重练时同样出拼音 + 田字格重写（复用同一组件）。
- 结算页答案展示：HAND 按 BLANK 方式显示词语文本（formatAnswerValue 扩展）。

### F-WORD-05 管理端
- QuestionValidator 题型白名单增加 HAND（校验规则同 BLANK：答案为非空文本/文本数组）。
- 管理端题目编辑页题型下拉增加「词语手写」。

## 7. 验收标准

1. 地图上已覆盖的 21 个 lesson 各出现第 4 关「词语闯关」，前 3 关通关后解锁；未覆盖课无此关。
2. 词语题只显示拼音，下方出现与字数等量的田字格；可用手指/触控笔书写，撤销/清空可用。
3. 全部格子写完后「对照答案」可用；点击显示正确词语，自评「写对了」判对、「写错了」判错并显示正确答案。
4. 答对计分符合现有规则，答错进错题本且可重写；词语题计入每日语文配额。
5. 三星/星级结算正常，错题本、结算页展示正常。
6. iOS 11 平板 Safari 实测：手写流畅、无滚动误触。
7. 管理端可新增/编辑 HAND 题并通过校验。
