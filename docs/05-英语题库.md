## 1. 背景与目标

在现有语文（人教版四上）、数学（北师大版四上）两科基础上，新增**第三个科目——英语**（人教版 PEP 四年级上册，三年级起点）。让孩子在闯关体系中同步练习英语，三科进度互相独立、每日限额各自一套。

教材目录与各单元词汇表须经家长按实体书逐条核对后方可出题（沿用项目惯例：以实体书为唯一内容依据）。

**题型用法说明（英语场景）**

| 题型 | 英语场景示例 |
|---|---|
| 单选 SINGLE | 看英文选中文释义 / 看中文选英文单词 / 情景对话选择 / 语法辨析 |
| 判断 JUDGE | 句子正误 / 语法辨析 / 交际用语是否得体 |
| 填空 BLANK | 单词拼写（自动忽略大小写与标点） / 句子补全 |
| 排序 ORDER | 连词成句 / 对话排序 |

> BLANK 判题自动忽略空格、标点、大小写（与语文 BLANK 一致），天然适配英语拼写题。
> 听力题需音频资源，本期不做（无音频素材库，且 iOS 11 离线兼容约束）。
> 知识点标签约定：职业词汇 / 家务词汇 / 外貌性格 / 爱好活动 / 场所词汇 / there be句型 / 常用表达 / 天气词汇 / 服装词汇 / 季节词汇 / 语法运用 / 拼写 等，便于管理端按知识点统计薄弱点。
