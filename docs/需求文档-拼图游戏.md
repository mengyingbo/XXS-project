# 需求文档：拼图游戏（v2.2 · 阶段 10）

> 状态：待用户确认
> 日期：2026-09-25
> 变更：删除"小鳄鱼爱洗澡"，替换为"拼图游戏"；游戏乐园其余部分（华容道/数独/成语接龙）不变

## 1. 背景与目标

小鳄鱼爱洗澡（网格水流模拟）操作门槛偏高，替换为更适合小学生、平板与电脑通用的**拼图游戏**。属于游戏乐园（v2.1）框架内的游戏替换：免登录、无积分、设备级进度存档，后端与数据库零改动。

## 2. 已确认决策

| # | 决策 | 结论 |
|---|------|------|
| 1 | 内置素材来源 | 代码绘制主题插画（不用课本扫描图，规避版权）；同时支持上传本地照片 |
| 2 | 集成方式 | 集成进游戏乐园（Vue 组件替换小鳄鱼），非独立三文件 |
| 3 | 科目范围 | 语文 + 数学（与现有科目体系一致，不含英语） |

## 3. 功能需求

### F-PUZZLE-01 入口与替换
- 游戏乐园大厅：🐊 小鳄鱼卡片替换为 🧩 拼图卡片
- 档案页入口副标题同步更新为"华容道 · 拼图 · 数独 · 成语接龙"
- 路由 `/games/water` 移除，新增 `/games/puzzle`
- 删除文件：`waterLevels.ts`、`WaterGame.vue`；games store 中 `water` 进度键替换为 `puzzle`（旧水进度自然废弃，不迁移）

### F-PUZZLE-02 素材
- **内置插画 6 张**（Canvas 代码绘制，卡通风格，标注课本来源）：
  - 语文（人教版四上）：《观潮》钱塘江大潮 / 《爬山虎的脚》攀墙 / 《蟋蟀的住宅》草丛洞府
  - 数学（北师大版四上）：《大数的认识》算盘 / 《线的认识》与角 / 《乘法分配律》? → 《买文具》生活场景（以实际绘制效果可读为准，绘制主题围绕四上单元名称）
- **上传图片**：`<input type="file" accept="image/*">`，FileReader 读取，居中裁剪为正方形后切块
- 图片选择页：横滑/网格缩略图，选中的图 + 难度 → 开始

### F-PUZZLE-03 难度
- 简单 3×3 / 普通 4×4 / 困难 5×5 / 挑战 6×6（全部开放，不设关卡锁）

### F-PUZZLE-04 玩法（交换式拼图）
- 拼图块网格铺满棋盘，随机打乱（保证初始不是完成态）
- **拖拽**：按住一块拖到另一块上松手 → 两块交换；支持鼠标与触屏（touch 事件，兼容 iPad/iOS 11）
- **点选交换**：轻点两块也可交换（同一交互双通道）
- 拖拽中拼图块放大 + 阴影反馈；放到目标位置有轻微吸附动画
- 可选开关：显示拼图块编号（默认关）

### F-PUZZLE-05 校验与完成
- 每块放对位置时淡入绿色边框提示（不锁定，仍可移动）
- 全部归位 → 弹窗"恭喜完成！"，显示用时、步数、星级，撒花动画

### F-PUZZLE-06 计时与步数
- 开始拼图自动计时，顶部实时显示；完成显示最终用时
- 每次交换计 1 步，顶部实时显示；完成显示总步数

### F-PUZZLE-07 操作
- 「重新开始」：同图同难度重新打乱，计时步数清零
- 「查看原图」：按住查看（按钮按下显示原图浮层，松开隐藏）；也可随时点缩略图参考
- 「换一张/换难度」：返回素材选择页

### F-PUZZLE-08 星级（进度入档）
- 星级按**步数效率**评定：设 N×N 块，基准步数 = 打乱时错位块数
  - 3 星：步数 ≤ 错位数 × 1.3
  - 2 星：步数 ≤ 错位数 × 1.8
  - 1 星：完成即得
- 进度 key：`puzzle-3` / `puzzle-4` / `puzzle-5` / `puzzle-6`，存入 games store（星级只升不降），大厅显示拼图总星数与完成难度数

## 4. 界面与交互
- 风格与游戏乐园一致（圆角卡片、大按钮、适合触屏）
- 布局：顶部（计时/步数/编号开关）→ 中间拼图棋盘（居中，宽度自适应）→ 底部（查看原图/重新开始/换一张）
- iOS 11 兼容：touch 事件（非 PointerEvent）、无 replaceAll、静态 import

## 5. 技术方案
- `views/games/Puzzle.vue` + `games/puzzleArt.ts`（Canvas 绘制内置插画）
- 切块：每块 `background-position` 偏移显示原图对应区域（DOM + CSS 方案，无需 canvas 切图）
- 打乱：Fisher-Yates，保证与原位不同块 ≥ 80%

## 6. 验收标准
1. 大厅与档案页入口显示拼图，小鳄鱼完全移除（路由/卡片/文件）
2. 6 张内置插画可见且可正常切块游戏
3. 上传本地图片可切块游戏
4. 四档难度均可完成一局
5. 鼠标拖拽、触屏拖拽、双击交换均可用；拖拽有视觉反馈
6. 计时、步数实时正确；完成后弹窗显示用时/步数/星级
7. 重新开始、查看原图、编号开关可用
8. 星级写入设备进度并在大厅展示
9. 构建通过（vue-tsc + vite），部署后生产可玩
