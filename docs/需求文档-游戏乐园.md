# 需求文档 · 游戏乐园（v2.1）

> 项目：小学随堂知识闯关游戏
> 版本：v2.1（阶段 9）
> 日期：2026-09-25
> 状态：待用户确认

---

## 1. 背景与目标

在 H5 孩子端**档案选择页底部**（用户标注的红框区域）新增「游戏乐园」入口，提供 4 款纯前端益智小游戏，作为知识闯关之外的思维训练补充。小游戏与闯关体系（科目、积分、每日限额）**完全独立**。

## 2. 已确认决策

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 登录要求 | **免登录随便玩**：无需选档案/PIN，打开即玩 |
| 2 | 积分/限额 | **完全独立**：不消耗每日题量/时长额度，不产生积分，不进商城 |
| 3 | 小鳄鱼实现程度 | **网格水流模拟版**：挖沙改地形、水按重力连续流动，含定时炸弹与蒸汽阀门 |
| 4 | 进度存档 | 设备级 `localStorage` 保存关卡解锁/星级（不与孩子档案关联，清除浏览器数据会丢失；提供"重置进度"入口）※ 本条为文档拟定，请确认 |

## 3. 总体设计

### 3.1 技术约束
- 纯前端实现，**后端与数据库零改动**；部署仅更新 H5 静态资源
- 沿用 Vue3 + Vite + TS；hash 路由 + **静态 import**（iOS 11 兼容）
- 游戏页面复用现有深色主题变量与触屏交互习惯（大按钮、防误触）

### 3.2 页面与路由
| 路由 | 页面 | 鉴权 |
|---|---|---|
| `/games` | 游戏乐园大厅（4 个游戏卡片 + 各自进度/星级展示） | 无 |
| `/games/klotski` | 华容道（传统华容道 / 路径规划双模式） | 无 |
| `/games/water` | 顽皮小鳄鱼爱洗澡 | 无 |
| `/games/sudoku` | 数独王者 | 无 |
| `/games/idiom` | 成语接龙 | 无 |

- **F-GAME-01 入口**：ProfileSelect 页底部新增「游戏乐园」横幅入口（含 4 个游戏小图标预览），点击进 `/games`；大厅每卡显示已完成关数/总关数与星数
- 进度读写统一封装 `stores/games.ts`（key：`xxs_games_progress`），含重置功能

## 4. 功能需求

### 4.1 F-GAME-02 华容道经典闯关

**模式 A：传统华容道**（4 列 × 5 行棋盘）
- 棋子：曹操 2×2、竖将 1×2×4、横将 2×1、兵 1×1；滑动移动，一步一格/多格
- 胜利：曹操移出底部出口
- 关卡：内置经典布局 ≥10 关（横刀立马、指挥若定、兵分三路、近在咫尺等），按最少步数难度排序，逐关解锁
- 辅助：步数统计、撤销、重排；"提示"用内置 BFS 求解器给出下一步最佳走法（每关限 3 次）

**模式 B：路径规划**（Rush Hour 式）
- 6×6 棋盘，横/竖滑块（长 2~3），红色目标车移到右侧出口
- 关卡：内置 ≥12 关，三档难度各 4 关，逐关解锁
- 辅助：步数统计、撤销、BFS 提示

**思维训练标注**：每关开始前显示 1 秒即逝的标注卡，如「思维重点：空间想象 · 步骤预判」，关卡列表页每关也带标签

### 4.2 F-GAME-03 顽皮小鳄鱼爱洗澡

- 网格 12×8，触屏**滑动挖沙**（泥土格可挖除，石头不可）
- **水流模拟**：水按重力下落→斜向→横向扩散的元胞自动机，逐帧（~100ms）更新；水流入浴缸 ≥ 目标量过关，水漏出屏幕底部过多则失败重试
- **变量元素**：
  - 定时炸弹：水流接触后倒计时 2 秒爆炸，炸开周围 3×3 的泥土/石头，并吞掉爆炸范围的水（关卡中用于炸开通道或制造陷阱）
  - 蒸汽阀门：点击切换开/关，控制对应管道格子通断，改变水流路径
- 关卡：内置手工设计 **12 关**（前 3 关教学：纯挖沙→引入炸弹→引入阀门），每关标注考察点（重力认知/路径规划/时机把控）
- 辅助：失败即时重试、过关星级（剩余水比例）

### 4.3 F-GAME-04 数独王者

- **三档难度**：四宫格（2×2）、六宫格（2×3）、九宫格（3×3）；四/六宫为题库内置（各 ≥30 题随机抽），九宫格为**生成器实时生成**（回溯生成终盘→对称挖洞→求解器验证唯一解）
- 交互：点格→弹数字键盘；冲突数字高亮标红；同行/列/宫自动淡显相同数字
- **智能提示系统**：①"检查"按钮标出当前所有错误 ②"提示"按钮自动填一格正确答案（每题限 3 次）
- 辅助：计时器、完成庆祝动画；四宫格适合入门、六宫格为四年级建议起点（界面标注推荐）

### 4.4 F-GAME-05 成语接龙

- 内置小学常用成语库 **≥200 条**（含拼音、释义），其中 ≥60 条含**出处/典故**（如"负荆请罪——《史记·廉颇蔺相如列传》…"）
- **四种题型**（每关混合出现）：
  1. **接龙**：给出成语，从 4 个选项中选下一个以尾字开头的成语（选项来自成语库首字索引）
  2. **填空**：成语缺 1~2 字，从候选字中补全
  3. **看图猜词**：emoji 组合猜成语（手写映射 ≥40 条，如 🐎🀄→马到成功 用更贴切组合），4 选 1
  4. **补全释义**：给释义选对应成语
- **关卡制**：6 关 × 每关 5 题，难度递进（常用→进阶）；答错即时显示正确答案与释义
- **通关典故展示**：每关通关页随机展示本关 1~2 个成语的出处典故卡片
- 辅助：错题即时讲解、关卡通关星级（按正确率）

## 5. 非功能需求

1. 全部游戏可离线运行（资源打包进构建产物，无新增网络请求）
2. 触屏友好：滑块拖动带跟手效果，棋子最小可点区域 ≥ 40px
3. 兼容 iOS 11 WebView（ES2017 语法边界，静态 import）
4. 每个游戏首屏 < 1s（大厅→游戏切换无长加载）
5. 进度存储失败（隐私模式）时静默降级为内存态，不影响游玩

## 6. 明确不做（本期）

- 排行榜、成就系统、游戏内商城
- 后端记录游戏数据、家长端查看游戏报告
- 自定义关卡编辑器
